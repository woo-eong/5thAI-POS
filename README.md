AI Market POS - 스마트 시장놀이 및 성능 평가 대시보드
초등학교 5학년 영어 9단원 《They Are Twenty Thousand Won》 시장놀이 수업을 위해 개발된 웹 기반 AI 손글씨 인식 포스기 및 교사용 성능 평가 대시보드입니다.

1. 개발 배경 및 기획 의도
현장의 교육적 한계:
초등학교 5·6학년 영어 단원에서는 물건을 사고파는 표현과 화폐 단위(10,000원 ~ 50,000원)를 학습하지만, 기존의 지면 카드나 단순 짝 활동 중심의 수업은 실제 화폐 단위의 철자 및 발음을 입체적으로 연결하여 확인하는 데 한계가 있었습니다. 또한 단순 암기 위주의 반복으로 인해 학생들의 몰입도가 떨어지고 실생활 연계 인공지능 기술을 경험할 기회가 부족했습니다.

해결 방안 및 접근:
학생들이 미니 화이트보드나 카드에 손글씨로 적은 가격을 웹캠 또는 사진 업로드를 통해 실시간으로 인식할 수 있도록 구글 티처블 머신(Teachable Machine) 이미지 분류 모델을 도입했습니다. 인식된 가격에 맞춰 상품 이미지와 영어 가격 태그를 시각화하고, 웹 브라우저 내장 TTS(웹 음성 합성) 기술을 연동하여 실제 마트 결제와 같은 대화형 상호작용이 이루어지도록 설계했습니다.

2. 프로젝트 핵심 기능
학생용 POS 웹앱 (index.html):

실시간 웹캠 스캔 및 손글씨 사진 파일 업로드 지원

가격대 키워드 기반의 조건문 매칭을 통해 상품 이미지 및 영어 표현(They're ten thousand won.) 실시간 시각화

웹 브라우저 TTS를 통한 자동 음성 발화 및 다시 듣기 기능 제공

교사용 성능 평가 대시보드 (eval.html):

테스트 이미지 일괄 업로드 및 파일명 기반 정답 자동 매칭 로직

전체 정분류율(Accuracy) 및 클래스별 정분류율 바 그래프 시각화

모델의 오인식 경향을 파악할 수 있는 혼동행렬(Confusion Matrix) 표 자동 생성

오답 이미지 썸네일 카드 갤러리 제공

3. 프로젝트 파일 구조
Plaintext
📦 ai-market-pos
 ┣ 📜 index.html         # [학생용] 실시간 웹캠 스캔, 사진 업로드, POS 결제 및 TTS 음성 발화 화면
 ┣ 📜 eval.html          # [교사용] 성능 평가 대시보드 (혼동행렬, 정분류율, 오답 썸네일 갤러리)
 ┣ 📜 model.json         # 구글 티처블 머신 모델 구조 파일
 ┣ 📜 metadata.json      # 모델 메타데이터 및 클래스 레이블 정보
 ┗ 📜 weights.bin        # 모델 가중치 바이너리 파일
4. 기술 스택
Frontend: HTML5, CSS3, Vanilla JavaScript

AI Model: Google Teachable Machine (TensorFlow.js)

Speech API: Web Speech API (SpeechSynthesis TTS)

Deployment: Vercel
